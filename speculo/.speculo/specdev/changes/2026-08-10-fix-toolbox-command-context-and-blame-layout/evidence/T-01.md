## 1. 实现摘要

Git Review `start` 现在只转发 VS Code 注入的 Source Control 上下文，并由仓库适配器验证 `id`、`label`、文件 URI、绝对路径与 Workspace Trust 后优先解析被点击的仓库；缺少可执行 `rootUri` 时明确返回 capability-unavailable，不回退到活动仓库。行历史命令接受行号菜单的 `{ uri, lineNumber }` 一基上下文，其他畸形对象仍返回 `invalid-input`。

Git Blame 格式器为每个已提交 hash 生成稳定实色与 14% 透明背景，未提交行不着色；Renderer 按当前文档最长显示文本计算统一 `ch` 列宽，绘制 `0.35em` 连续色条和整列淡背景，不改变代码正文。17 个贡献命令的中英文标题均直接以 `toolbox-` 开头，命令 ID、配置键、Gateway 与 Extension API 保持不变。版本已提升至 `0.1.2` 并生成本地 VSIX。
