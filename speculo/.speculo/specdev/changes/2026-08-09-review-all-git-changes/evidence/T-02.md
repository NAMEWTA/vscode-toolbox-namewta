## 1. 实现摘要

已实现受信任工作区的只读 Git Review Port Adapter。它使用 NUL 分隔的 porcelain v2 状态和 numstat 解析，将 staged、unstaged 与 untracked 归并为当前路径唯一的描述；删除、重命名、无 `HEAD`、二进制、submodule 与不可读取内容均不会被静默遗漏。

Adapter 仅经现有参数数组 Git Runner 调用 `rev-parse`、`status`、`diff --numstat` 与 `show`，并保留 Runner 的超时、取消、输出上限与子进程清理。路径、Git 输出、仓库物理根和内容请求均在扩展边界验证；`.git` 元数据路径、目录穿越、畸形 NUL 记录和错误的 `HEAD` 退出码都会拒绝。

所有 T-01 Git Review Handler 已在唯一领域注册点注册，能力通过类型化 Gateway 可观察。注册函数返回 Session 的 `Disposable`，供拥有组合根的 T-03 纳入 `DisposableStore`。
