## 1. 实现摘要

新增纯 Core 的 Git Review 领域：它定义可序列化的审核项、内容、快照与 Port 契约，并以单 session 状态机管理稳定排序、导航、显式审核、跳过、stale、刷新、完成、替换和取消。新增命令已进入 `ToolCommandMap` 并在运行时校验边界输入；尚未注册到 `ToolRegistry`，因此本 Ticket 不会把尚未接入真实 Git 的能力伪装为可用。

刷新只按稳定内容身份保留既有处理状态；路径相同而内容身份变化的项目会回到 `unreviewed`。Core 不包含 VS Code、Node、React 或 DOM 依赖，也不执行 Git 操作。
