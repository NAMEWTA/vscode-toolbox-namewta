## 1. 实现摘要

已交付完整 Git Review VS Code 体验。Manifest 贡献八个用户可绑定命令、`scm/title` 启动入口和 Source Control Review Queue；命令不带默认快捷键，所有业务操作经类型化 `ToolboxGateway` 执行。

`GitReviewSessionController` 以单一 session 快照投影队列、状态栏和原生 `vscode.diff`。它区分普通导航、显式审核和跳过，处理 stale/refresh、局部内容失败、取消、替换确认、完成总结、过期请求与扩展停用的资源释放。文本使用临时只读内容 URI，特殊项显示只读摘要；URI 不含仓库绝对路径。

组合根仅注册 feature disposable 与命令，不在激活时创建 Review UI、扫描工作区或执行 Git。仓库上下文适配器先验证 Trust，再以参数数组执行只读 `rev-parse`；活动文件优先，多个候选才显示选择器。
