## 1. 实现摘要

Reader 从活动行打开并高亮，单击/双击/Enter 通过已验证 source URI 回到同一行；文档 change 仅标 stale，save/Refresh 才创建新 generation。dispose 取消请求并清理 panel、listener、message adapter 和 session model。
