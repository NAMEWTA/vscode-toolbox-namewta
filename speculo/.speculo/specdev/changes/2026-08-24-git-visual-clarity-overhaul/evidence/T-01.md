## 1. 实现摘要

Git Compare revision URI 用真实仓库相对路径作为 pathname，并保留不透明 token 授权。Reader 将每个连续 commit 归并为跨 Blame/Code 两列的共享色块，SHA 和摘要仅在块首显示，info 在 React 内打开可访问模态。编辑器旧注解实现已删除，替换为固定日期/作者/可选版本编号列、连续行合并、heat 色条与行首 hover。
