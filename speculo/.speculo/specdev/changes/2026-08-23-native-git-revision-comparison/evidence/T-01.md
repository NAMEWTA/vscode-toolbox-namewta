## 1. 实现摘要

Git Compare 从 Explorer 双 TreeView 和隐式 reference 状态迁移到 Source Control 标题栏图标。用户分两步选择 base 与 target，target 默认 HEAD；两端均支持分页历史或 4 到 64 位 SHA 前缀。前缀通过 typed gateway 固定为完整 OID，随后执行直接 `base -> target` 快照比较，并由公开 `vscode.changes` 一次展示全部文件。
