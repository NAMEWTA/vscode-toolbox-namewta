## 1. 实现摘要

Compare 与 Review 现在共享经过 SCM 上下文验证的仓库解析器和公开 `vscode.changes` presenter。Revisions 输入通过 typed Gateway 搜索 `--all` 提交消息与 `for-each-ref` ref 名，支持取消、防抖和代际隔离。Review 删除 React Webview、结构化 patch 链路与专用依赖，改用 `layer/path` token URI 惰性读取 HEAD/index/worktree，并把 Stage、Unstage、确认后 Discard 放入 Review Queue。Relative / Absolute Reference 分别增加 C/V 默认快捷键。

- **本变更引入并已修复：** 两个测试工厂缺显式返回类型；旧 Extension Host 断言仍等待 Webview；移除 Webview entry 后增量构建保留陈旧 `dist` 资产。分别通过类型补全、原生 Tab 断言和构建前清理 `dist/webview` 解决。

- **验证工件无效并已修复：** 初始 Speculo scaffold 使用旧字段和非标准章节；已按 schema v3 补齐并通过 implement validator。
