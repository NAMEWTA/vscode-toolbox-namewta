## 1. 实现摘要

Reader 已从逐行交错、整行点击和复制工具栏改为 Blame/Code 两个独立连续 DOM 文本流。Blame 使用稳定 commit 色块，Code 保持编辑器背景并使用同色细标记；普通文本点击不发送 Host 消息，源码和提交详情只能通过显式 Lucide 图标触发。列宽在当前 React Panel 会话内保留，软换行后的行高由 `ResizeObserver` 同步，大文件保留完整 logical line DOM 并使用 `content-visibility` 抑制离屏绘制。
